# Acknowledgements

Tihulu Minimized Windows interoperates with the COSMIC desktop and uses the public APIs provided by System76's COSMIC projects, including `libcosmic` and `cosmic-protocols`.

The project was motivated by observed resource-exhaustion failures and public COSMIC bug reports involving minimized-window handling. It is implemented as a separate AGPL-3.0-only applet rather than distributing a modified copy of the stock `cosmic-applet-minimize` source files.
